# 검증 범위

## 클라우드에서 수행

```bash
python3 tools/bootstrap_android.py
tools/cloud-gradle.sh :core:test :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
python3 tools/package_delivery.py
```

전달본의 Git 커밋, 테스트 수, APK 서명·정렬과 SHA-256은 `dist/BUILD_REPORT.json`에 기록합니다. 출력은 `dist/VERIFY_LOG.txt`, 정적 검사는 `dist/LINT_REPORT.html`에 보관합니다.

자동 시험은 다음을 확인합니다.

- 이름·좌표·반경, 활성 상점 100곳 한도와 기존 상점 수정
- 반복 진입·나감·30분 경계·시계 역행·꺼진 상점
- Android 버전별 위치·알림·Google Play 서비스 준비 조건
- SQLite/Room 저장과 재열기, 삭제·비활성화·전체 알림 중지·수정 전 핀의 지연 이벤트
- 등록 완료·권한 부족·서비스 오류·시간 초과·등록 중 설정 변경
- 이름만 바꿀 때 등록 유지, 포그라운드·복구 시 강제 재등록
- 알림 내용·상점 상세 진입·ID 충돌·알림 취소
- 전송 거부 시 방문·쿨다운을 소비하지 않는 처리와 진입·이탈 순서 유지
- Compose Activity 시작, 목록 갱신과 설정 진입
- GitHub 업데이트 버전·Android 지원·허용 URL·다른 앱/서명 거부
- 다운로드 체크섬·부분 파일 정리·실패 재시도·취소·설치 직전 재검증
- 새 앱 이름·업데이트 카드·이름 검색 버튼과 Google 연결 대기 화면
- Google 지도 앱/웹 링크의 이름 인코딩과 좌표, 검색 결과의 이름·좌표 검증
- Firebase Hosting 주소 검증, 하루 간격과 시계 역행
- 자동 확인의 중복 알림·권한 거부·중간 해제·동시 실행·네트워크 재시도, 알림 표시 직전에 해제한 경우 표시 취소
- 업데이트 알림 내용과 설정 화면 진입, 자동 확인 스위치

순수 Kotlin 시험은 JVM, Android 어댑터·Room·Compose 시험은 Robolectric Android 35에서 실행합니다. 외부 위치 이벤트는 테스트 대역으로 검증합니다. 지도 네이티브 렌더링은 이 시험에서 실행하지 않습니다.

## 실제 기기에서 확인 필요

클라우드에는 Android 휴대폰이 연결되어 있지 않습니다. 다음 항목은 자동 시험만으로 성공했다고 판단하지 않습니다.

- 설치·업데이트, 실제 지도 표시·핀 선택
- 실제 Firebase Hosting 배포·응답과 휴대폰의 예약 업데이트 확인·알림
- Google API 키 연결 후 Places 검색 응답과 지도 위 내 위치 표시. 현재 전달 APK에는 키가 없습니다.
- 잠금·백그라운드에서 근접 이벤트와 알림 도착
- 실내·야외 오차, 제조사 절전, 재부팅·앱 업데이트 복구
- 권한 거부 후 재요청과 Android 설정에서 ‘항상 허용’으로 변경
- 위치·알림 권한 철회와 강제 종료 후 복귀

사용 안내서의 기기 시험 순서를 따르세요. ‘알림 준비 완료’는 등록 요청 성공을 뜻하며, 모든 위치 이벤트가 즉시 전달됨을 보장하지 않습니다.

## 작업 중 결정

- 기존 클라우드의 격리된 `work` 체크아웃을 사용했습니다.
- 사용자 설계 승인과 직접 구현 지시에 따라 이 세션에서 구현했습니다.
- 위치·반경·알림 선택 변경 시 내부 등록 버전을 올려 과거 핀의 지연 이벤트를 무시합니다. 이름 변경은 방문 상태를 유지합니다.
- 앱 활성화 시 신선하고 정확한 위치로 반경 밖인 상점만 상태를 보정합니다. 반경 안의 첫 진입은 미리 소비하지 않으며, 휴대폰이 꺼진 동안의 출입은 추측하지 않습니다.
- 같은 프로세스 안에서 이름 수정은 성공한 등록을 재사용합니다. 앱 재진입·복구는 강제 재등록합니다.
- 개인용 APK는 ARM64·ARMv7로 한정했습니다. ChromeOS·x86 에뮬레이터는 대상에 포함하지 않습니다.
- 최종 별도 코드 검토에서 발견한 알림 전송 실패·이벤트 순서 문제를 재현 테스트로 수정했습니다. 전송에 성공한 뒤 같은 DB 트랜잭션에서 상태를 저장하며, 수신 즉시 큐에 넣고 한 소비자가 처리합니다. 비동기 수신 제한 시간에는 큐 대기 시간도 포함합니다. 앱 프로세스 종료나 제한 시간 초과는 별도 복구를 예약하며 이벤트의 완전한 전달은 보장하지 않습니다.
- 다른 상점의 알림을 누르면 편집 화면과 지도를 상점 ID로 새로 만들어 이전 지도 위치가 남지 않도록 했습니다.

정적 검사 경고 중 버전 갱신 제안, ChromeOS ABI, 아이콘·KTX 권장은 현재 기능 실패를 뜻하지 않습니다. 검사 오류는 전달 전 해결합니다. 서명 키는 소스 ZIP에 포함하지 않으므로, 원래 키 없이 만든 APK로 기존 설치를 업데이트할 수 없습니다.

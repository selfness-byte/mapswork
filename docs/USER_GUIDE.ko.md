# 이곳 사용 안내 — 0.2.0

앱에 등록한 상점의 근처에 도착하면 휴대폰 알림으로 알려 줍니다. Google 지도 저장 목록을 자동으로 읽는 기능은 이번 버전에 없습니다.

## 1. 설치

1. Google Play 서비스가 설치된 Android 8.0 이상 휴대폰을 준비합니다. ARM64와 ARMv7을 지원합니다.
2. `mapswork-0.2.0-test.apk`를 휴대폰으로 옮깁니다.
3. 휴대폰 파일 앱에서 APK를 엽니다. 필요한 경우 해당 파일 앱에 ‘알 수 없는 앱 설치’를 허용합니다.
4. 설치한 **이곳** 앱을 엽니다. 기존 ‘가까운 상점’과 같은 앱이므로 삭제하지 않고 업데이트하세요.

개인 기기 시험용 디버그 서명 APK이며 Google Play 배포용 파일은 아닙니다. 클라우드 자동 검증을 수행했지만 실제 휴대폰 시험은 아직 하지 않았습니다.

## 2. 필요한 권한

앱 위쪽의 큰 **설정** 버튼을 누릅니다.

1. **정확한 위치**: 위치 권한을 허용하고 ‘정확한 위치’를 켭니다.
2. **백그라운드 위치**: Android 10 이상에서 ‘항상 허용’을 선택합니다. Android 11 이상은 안내에 따라 휴대폰 앱 설정 → 권한 → 위치로 이동합니다.
3. **알림**: Android 13 이상에서 알림 권한을 허용합니다. 앱 알림과 ‘저장한 상점 근처 알림’ 채널도 켜져 있어야 합니다.
4. 휴대폰 **위치 사용**을 켜고 Google Play 서비스를 사용할 수 있는지 확인합니다.
5. **전체 알림**을 켭니다. 처음에는 꺼져 있습니다.

권한을 철회해도 저장한 상점은 유지됩니다. 앱에 다시 들어오면 현재 상태를 확인합니다. 준비 상태가 부족한 권한이나 위치 설정을 안내합니다.

## 3. 상점 등록

1. 목록에서 **상점 추가**를 누릅니다.
2. 이름을 입력합니다. 앞뒤 공백을 제외하고 1~80자입니다.
3. **상점 이름 검색**으로 이름을 찾을 수 있습니다. 현재 키 없는 APK는 Google 지도 앱/웹 검색을 엽니다. 앱 내부 검색을 연결한 버전에서는 결과를 선택하면 이름과 위치가 채워집니다.
4. **내 위치**는 현재 위치를 한 번 확인합니다. 연결된 지도에서는 파란 마커를 표시하고 중심을 이동합니다. **내 위치를 상점 위치로 선택**을 누르면 현재 위치를 저장할 상점 위치로 지정합니다. 연결된 Google 지도를 직접 눌러 고른 상점 위치는 빨간 마커로 표시됩니다.
5. 반경을 고릅니다. 기본 **200m**, 선택값 100m·500m·1km입니다.
6. **이 상점의 알림**을 켜거나 끄고 **저장**을 누릅니다.

지도·검색에는 인터넷 연결이 필요합니다. 로딩 실패·검색 취소 시 이름과 선택한 위치는 유지됩니다. 현재 Google API 키가 없어 앱 내부 지도는 **Google 지도 연결 대기**로 표시합니다. **Google 지도에서 보기**는 별도 지도 앱/웹을 엽니다. 여기서 찾은 장소는 자동으로 가져오지 않습니다. 앱 내부 지도·검색 활성화는 `GOOGLE_MAPS_SETUP.ko.md`를 따릅니다.

알림을 켠 상점은 최대 100곳입니다. 알림을 끈 상점은 추가로 보관할 수 있습니다. 기존 상점의 이름 수정은 한도에 영향을 주지 않습니다.

## 4. 알림과 관리

- 반경에 들어오면 ‘저장한 상점 근처에 도착했어요’ 알림을 보냅니다.
- 같은 상점 안에 머무는 동안 반복 알림을 억제합니다.
- 나갔다가 다시 들어와도 이전 알림으로부터 최소 30분이 지나야 다시 알립니다.
- 알림을 누르면 해당 상점을 엽니다. 이미 삭제된 상점은 목록으로 이동합니다.
- 목록의 스위치로 상점별 알림을 끕니다. 전체 알림은 설정에서 끕니다.
- 목록에서 상점을 누르면 수정·삭제할 수 있습니다.

Google Play 서비스의 시스템 근접 감지를 사용합니다. 도착과 동시에 알림이 뜨는 것은 보장되지 않으며 Android 절전·실내 오차·통신 상태에 따라 몇 분 이상 늦어질 수 있습니다. 첫 시험에는 500m 반경을 권장합니다.

재부팅과 업데이트 후 감지 복구를 예약합니다. 앱을 **강제 종료**했거나 권한을 바꾼 뒤에는 앱을 다시 열고 상태를 확인하세요. 제조사 절전으로 알림이 제한되면 앱의 백그라운드 사용 설정을 확인하세요.

## 5. 저장·비용·개인정보

- 상점과 방문 알림 시각은 휴대폰 내부에 저장됩니다. 자동 클라우드 백업·기기 간 자동 전송은 꺼져 있습니다.
- 앱 삭제·앱 데이터 삭제 시 상점도 사라집니다. 내보내기·복구 기능은 이번 버전에 없습니다.
- Google Play 서비스가 근접 위치를 판단합니다. 앱 서버에 위치 기록을 보내거나 이동 경로를 계속 기록하지 않습니다.
- 지도·검색 요청 시 Google에 요청한 영역·검색어와 서비스에 필요한 앱·네트워크 정보가 전달됩니다. Google 지도와 공식 검색 화면의 출처 표시를 유지합니다.
- 앱 서버·GCS 저장소는 사용하지 않습니다. Google API 키를 연결하면 검색 사용량에 따라 프로젝트 소유자에게 요금이 발생할 수 있습니다. 현재 키 없는 APK는 앱 내부 지도 API를 호출하지 않습니다.

## GitHub 업데이트

**설정 → 업데이트 확인**을 누릅니다. 새 버전이 있으면 변경 내용을 확인하고 **업데이트 다운로드 → 업데이트 설치**를 누릅니다. Android에서 ‘이 출처 허용’을 요구하면 허용한 뒤 설치 확인 화면에서 결정하세요. 자동 설치하지 않습니다.

공개 GitHub의 `downloads/update.json`으로 버전을 확인하고 APK 해시·앱 식별자·버전·서명을 검사합니다. 같은 앱 서명으로 설치하면 기존 상점 데이터가 유지됩니다. 앱을 삭제하고 다시 설치하면 데이터는 사라집니다. 인터넷이 끊겨 실패하면 재시도할 수 있습니다. 비공개 저장소나 배포 파일이 없어 읽지 못하면 오류를 표시합니다.

0.1.0에는 이 업데이트 메뉴가 없으므로 0.2.0 APK를 한 번 직접 설치해야 합니다. 그 이후 더 높은 버전부터 메뉴로 업데이트할 수 있습니다.

## 6. 실제 휴대폰 시험

아래 항목은 클라우드에서 실제 기기 시험을 하지 않았습니다. 실내 GPS로 판단하기 어려우면 안전한 야외에서 시험하세요.

1. 저장 후 앱을 닫았다 다시 열어 이름·위치·반경이 유지되는지 확인합니다.
2. 권한과 전체 알림을 켜고 준비 완료·등록 수를 확인합니다.
3. 현재 위치에서 충분히 떨어진 상점을 500m 반경으로 저장합니다. 화면을 잠그고 반경 안으로 이동해 알림이 오는지 확인합니다.
4. 그곳에 머무는 동안 같은 알림이 계속 오지 않는지 확인합니다.
5. 충분히 나갔다가 30분 이후 다시 들어와 새 알림이 오는지 확인합니다.
6. 상점 알림·전체 알림을 끄고 이동했을 때 새 알림이 생기지 않는지 확인합니다.
7. 재부팅 후 잠시 기다렸다가 근접 알림을 확인합니다. 안 되면 앱을 열고 상태·권한을 확인합니다.
8. 알림을 눌러 상점이 열리는지, 삭제한 상점의 오래된 알림이 앱을 종료시키지 않는지 확인합니다.

## 7. 외장하드 M에 보관

클라우드는 Mac의 M에 직접 접근하지 않습니다. 완성 파일을 **다운로드한 뒤** Finder에서 **M → 공통작업 → mapswork**로 옮깁니다.

**`mapswork-complete.zip` 하나를 받으면 아래 파일이 모두 들어 있습니다.** 보관할 때는 ZIP 그대로 두고, 설치할 때 필요한 파일을 꺼내도 됩니다.

- `mapswork-0.2.0-test.apk`: 설치용
- `mapswork-source.zip`: 완료한 소스·문서
- `USER_GUIDE.ko.md`: 이 안내서
- `GOOGLE_MAPS_SETUP.ko.md`: 지도·검색 키 연결 안내
- `BUILD_REPORT.json`, `VERIFY_LOG.txt`, `LINT_REPORT.html`: 검증 기록
- `THIRD_PARTY_NOTICES.md`: 외부 소프트웨어·지도 출처
- `SHA256SUMS.txt`: 파일 체크섬

Mac에는 Android Studio·에뮬레이터·빌드 캐시를 설치할 필요가 없습니다. 보관과 휴대폰 전송만 하면 됩니다. 파일을 저장하는 것만으로 Mac에서 앱 프로세스가 실행되지는 않습니다.

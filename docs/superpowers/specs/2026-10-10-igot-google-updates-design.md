# 이곳 0.2 — Google 지도와 GitHub 업데이트

## 요청과 목적

앱 이름을 `이곳`으로 바꾸고 첫 화면의 설정 진입 버튼을 크게 만든다. 설정에서 GitHub APK 업데이트를 확인하고 설치할 수 있어야 한다. 상점 추가에는 Google 지도, 지도 위 내 위치 표시, 상점 이름 검색을 제공한다. 저장한 상점의 기존 근처 알림과 데이터는 유지한다.

사용자는 Google Cloud 프로젝트/API 키가 아직 없다고 답했다. 결제 계정이나 유료 API는 대신 개설하지 않는다. 기본 전달 APK는 Google 키 없이 빌드하며, 앱 내부 Google 지도·Places 검색은 키를 설정한 빌드에서 동작한다. 그 전에는 Google 지도 앱/웹에서 위치 보기·이름 검색과 현재 위치를 상점 위치로 선택하기를 제공한다. 실제 지도 표시, 검색 응답, 설치와 근처 알림은 휴대폰 확인이 필요하다.

## 앱과 화면

- Android 8 이상, `com.selfness.mapswork`, Room v1 유지. versionCode `2`, versionName `0.2.0`, 기존 테스트 서명 유지.
- 첫 화면 제목과 앱 라벨 `이곳`. 설정 버튼은 톱니 아이콘 28dp와 `설정` 글자, 최소 56dp 높이.
- 설정 화면 위쪽에 업데이트 카드: 현재 버전, 업데이트 확인, 변경 내용, 다운로드, 설치. 자동 검사·자동 설치는 하지 않는다.
- 상점 이름 옆/아래 `상점 이름 검색` 버튼. Google Places 공식 검색 화면을 사용하고 선택한 장소의 이름·위치를 편집기에 채운다. 저장은 사용자가 누른다. 취소·오류 시 기존 이름과 위치를 유지한다.
- `내 위치`는 요청할 때 위치를 한 번 조회하고 Google 지도에 파란 마커로 표시한다. 상점은 빨간 마커로 구분한다. 지도를 이동한 뒤 같은 위치에서 다시 눌러도 중심을 이동한다. 지도 탭은 상점 위치를 선택한다.
- 키가 없는 경우 지도 연결 대기를 명시한다. Google 지도 앱/웹 열기와 현재 위치를 상점 위치로 선택하는 기능은 제공한다. 화면에 미설정 지도를 작동하는 것처럼 표시하지 않는다.

## Google 연결

Google Maps Android SDK `19.2.0`, Places Android SDK `4.3.1`. MapLibre/OSM 타일 코드를 제거한다. Google 지도 기본 출처 표시와 Places 공식 검색 화면의 출처 표시를 보존한다.

빌드 키는 `MAPSWORK_GOOGLE_MAPS_API_KEY` 환경 변수 또는 Git에서 제외하는 `local.properties`의 `mapswork.googleMapsApiKey`에서 읽는다. 코드·문서·Git에는 키 값을 넣지 않는다. Android 배포 키는 APK에서 확인 가능하므로 Android 패키지명과 서명 SHA-1, Maps SDK for Android 및 Places API (New)로 제한한다. 발급 프로젝트의 결제 계정과 검색 사용량 요금을 사용자가 관리한다. 예산 알림은 비용을 차단하지 않는다.

## GitHub 업데이트

기존 GitHub `downloads/` APK 배포 경로를 사용한다. GitHub API/Release가 필요하지 않다. 공개적으로 읽을 수 있는 `downloads/update.json`을 HTTPS로 읽는다. 버전 코드, 최소 Android, APK URL, SHA-256, 변경 내용을 포함한다. GitHub 인증 토큰은 APK에 넣지 않는다. 비공개 저장소라 읽지 못하면 명확한 오류를 표시한다.

APK는 이 저장소의 `raw.githubusercontent.com` HTTPS 경로만 허용한다. 매니페스트 최대 32KiB, APK 최대 80MiB, 네트워크 시간 제한을 둔다. 임시 파일에 받고 SHA-256, 앱 패키지, 버전, 기존 설치 앱의 서명과 일치하는지 확인한 후에만 설치용 파일로 옮긴다. 실패 시 부분 파일을 삭제한다. 설치 직전에 다시 검증한다. 다운그레이드·다른 앱·다른 서명 APK를 거부한다.

`FileProvider`로 검증한 캐시 APK만 Android 설치 화면에 전달한다. ‘이 출처 허용’은 사용자가 설치 버튼을 누를 때 필요하면 설정 화면으로 안내한다. 설치 여부는 Android 확인 화면에서 사용자가 결정한다. 같은 패키지와 서명으로 설치해야 기존 상점 데이터가 남는다.

## 검증과 전달

업데이트 버전·URL·서명·체크섬 규칙과 다운로드 실패/재시도/부분 파일 삭제를 테스트한다. 기존 63개 테스트를 유지하고 첫 화면·업데이트 화면의 실제 Compose 진입을 확인한다. Google SDK 컴파일, APK, lint, APK 서명과 ZIP 검증을 실행한다. Google API 키가 없어 실제 SDK 통신·지도 표시를 통과했다고 주장하지 않는다.

소스를 먼저 커밋하고 완료 ZIP/APK를 생성한다. APK 해시로 업데이트 매니페스트를 만들고 기존 GitHub 브랜치에 전달 파일을 게시한다. M에는 직접 쓰지 않는다.

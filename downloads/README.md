# 완성 파일 다운로드

## 가까운 상점 0.1.0 검증용

- [전체 파일 ZIP 다운로드](https://github.com/selfness-byte/mapswork/raw/refs/heads/codex/nearby-shop-alert/downloads/mapswork-complete.zip) — APK·소스 ZIP·한국어 안내서·라이선스·검증 기록 포함
- [Android APK 다운로드](https://github.com/selfness-byte/mapswork/raw/refs/heads/codex/nearby-shop-alert/downloads/mapswork-0.1.0-test.apk)
- [SHA-256 체크섬](SHA256SUMS.txt)

Google Play 서비스가 있는 Android 8.0 이상 ARM 휴대폰용입니다. 자동 테스트 63개와 빌드·정적 검사·서명·16KB 정렬을 확인했습니다. 실제 휴대폰의 지도·백그라운드 근접 알림·재부팅 시험은 아직 하지 않았습니다.

파일을 다운로드한 뒤 **M → 공통작업 → mapswork**로 옮기세요. 클라우드는 M에 직접 저장하지 않습니다. 소스 ZIP은 검증한 소스 커밋에서 만들며, 정확한 커밋과 검증 결과는 전체 ZIP의 `BUILD_REPORT.json`에 기록합니다.

GitHub API 접속이 클라우드 프록시에서 차단되어 Release 대신 저장소 폴더로 전달합니다. 이 폴더는 Git 소스 아카이브에서 제외합니다.
